# Examples — flexible use, not layout templates

1. **中文定量研究，回归结果**：「使用 $academic-style-intelligence，结合我的回归表，判断是否应绘制系数及置信区间图；如适用请输出可编辑矢量图，不要自动改成变量关系框图。」
2. **中文理论研究**：「使用 $academic-style-intelligence，根据我写出的理论机制选图并绘制；我没有指定必须是流程图或自变量—因变量图。」
3. **中文结构方程研究**：「使用 $academic-style-intelligence，依据测量模型和结构模型中的真实路径设计图；不要自动添加控制变量或 H 标签。」
4. **参考图（可选）**：「使用 $academic-style-intelligence，参考附图的视觉层次和排列方式，用我论文中的内容重新绘图，保留真实研究关系。」
5. **目标期刊（可选）**：「使用 $academic-style-intelligence，我准备投《某期刊》，请核实可访问的图表规范和相近方法论文的例子，再提出适配方案。」
6. **两者都有（可选）**：「使用 $academic-style-intelligence，我给了图片和期刊名称，请综合参考，不要为贴合外观改变论文中的事实。」
7. **English machine learning**: “Use $academic-style-intelligence to read this ablation study and recommend a suitable result figure; don't assume it needs a neural-network architecture diagram.”
8. **学术写作**：「使用 $academic-style-intelligence，按学科与投稿语境修改这段论述，保持事实、数据和原本引用不变。」

These are usage scenarios; user inputs can be free form and mixed.
