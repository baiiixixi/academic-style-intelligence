# Manual evaluation scenarios (not yet run within Codex)

These evaluate *judgment*, not adherence to fixed templates.

1. Chinese empirical paper with regression coefficients and CIs: output a relevant result visualization, not reflexively an IV–DV box.
2. Chinese qualitative interview research: avoid inventing independent/dependent variables; structure coding themes or research process if useful.
3. Chinese SEM work: distinguish measurement and structural paths, do not invent hypotheses.
4. English ML ablation experiment: prefer relevant comparison, not always model architecture.
5. User provides a reference image: reuse visual conventions, not content; if unreadable, disclose it.
6. User supplies a journal without inspectable official rules: no invented constraints.
7. Journal and reference disagree: preserve scientific meaning and verified hard requirements; explain necessary tradeoffs.
8. Prose revision: preserve original claims, data, sources, and disciplinary register.
